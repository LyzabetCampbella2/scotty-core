## Implementation limitations
The included module provides source *assessment templates*, not source retrieval or actual verification. User-supplied metadata cannot establish truth. No autonomous schedules, live knowledge updates, memory writes, project assignments, or database permissions are activated. Authorization must be enforced by authenticated server-side services. No production modifications authorized.
